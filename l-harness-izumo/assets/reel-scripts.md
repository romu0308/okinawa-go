# Instagram リール台本 12本（3〜4週間分）

週3〜4本投稿する前提。全部のリールで **コメント誘導は「縁切り」に統一**する
（エルグラムの自動DMキーワードを1つにするため）。

## 共通の型

```
0〜2秒　フック（画面に大きい文字。読み上げも同じ）
2〜15秒 本体（3〜5項目のリスト or あるある）
15〜20秒 CTA
```

## 共通CTA（毎回同じ文言でいい）

画面文字：
```
自分がどのタイプか、1分で分かる診断つくった
コメントに「縁切り」で送るよ
```
読み上げ：
「自分がどのタイプか分かる診断を作った。コメントに『縁切り』って書いてくれたら送る。」

## 撮り方（顔出しなし）

- 黒背景＋白の大きいゴシック文字。1画面1メッセージ
- BGMは無音〜控えめ。テロップを読ませる作り
- 音声を入れるなら合成音声で統一する（声の指紋を残さない）
- 素材写真は使い回さない。他アカウントと同じ画像を使わない

## 1. こんな人とは縁を切っていい【5選】
フック：**「いい人」なのに、会うと疲れる人の特徴**
本体：
・会った後、なぜかスマホをだらだら見てしまう
・話の8割が愚痴で、解決する気はない
・こちらの予定を「空いてるでしょ」で埋めてくる
・褒め方が、いつも他人との比較
・断ると、理由を根掘り葉掘り聞いてくる

## 2. 縁を切れない人の口ぐせ【3つ】
フック：**この口ぐせが出たら、あなたは縁を握ってる**
本体：
・「でも、悪い人じゃないから」
・「昔は良くしてもらったし」
・「私が我慢すれば丸く収まる」
締め：3つとも、相手じゃなくてあなたの誠実さの話だ。

## 3. 縁の切り方には順番がある
フック：**いきなり絶縁するから、こじれる**
本体：
①返信速度を落とす（即レスをやめる）
②会う頻度を落とす（3回に1回断る）
③物理的な距離を取る
④それでも詰められたら、短く事実だけ
締め：①だけで2週間やってみてほしい。

## 4. 断るときに、理由を言ってはいけない
フック：**断り方で、9割決まる**
本体：
・理由を長く言う → 相手に交渉の余地を渡す
・「その日は無理」で終わる → 交渉の余地がない
・代案を出す必要もない
締め：優しい人ほど説明しすぎて、また誘われる。

## 5. 楽しかった記憶、いつのやつ？
フック：**あなたが握ってるのは、縁じゃなくて思い出かもしれない**
本体：紙に線を引いて、左に「楽だった瞬間」右に「消耗した瞬間」を書く。
見るのは数じゃなく、左側の一番新しい日付。
締め：それが2年前で止まってるなら、答えは出てる。

## 6. 疲れる相手が特定できない人へ
フック：**誰のせいか分からないのに、しんどい人**
本体：
・夜、その日会った人の名前だけメモする
・疲れた日は名前の横に✕
・3日で、✕の隣に同じ名前が並ぶ
締め：並ばなかったら、原因は人じゃなく「引き受けてる役割」だ。

## 7. 縁を切るのは冷たいことじゃない
フック：**中途半端に付き合い続ける方が、よっぽど不誠実**
本体：
・人が深く付き合える人数には限りがある
・合わない縁を握ったまま接するのは、相手にも失礼
・「切る」は攻撃じゃなく、自分の時間を取り戻す整理
締め：あなたの時間を誰に使うかは、あなたが決めていい。

## 8. 「恩がある」で縛られてる人へ
フック：**恩は、その場で返せば縁にならない**
本体：
・奢られたら次は奢る
・助けられたらその週に返す
・貸し借りを溜めない人は、縁に縛られない
締め：溜めた恩は、10年後の断れなさになる。

## 9. 縁が切れた後に必ず来るもの
フック：**罪悪感が出るのは、正常だ**
本体：
・切った直後、3日〜2週間で必ず来る
・「私が冷たかったのでは」と思い始める
・これは相手が正しかった証拠ではない
締め：罪悪感が出るのは、あなたが誠実な人だからだ。

## 10. 最初がやたら良い人に気をつけろ
フック：**距離の詰め方が速い人ほど、後で断れなくなる**
本体：
・初対面で悩みを打ち明けてくる
・「あなたにだけ話す」と言う
・最初の心地よさが強いほど、後で断りにくい
締め：判断基準は相手の性格じゃなく、会った後の自分の状態。

## 11. 家族や職場は切れない。でも消耗は減らせる
フック：**切れない相手には「境界線」を引く**
本体：
・関わる時間帯を決める（夜は返さない）
・話題の範囲を決める（仕事の話だけ）
・引き受ける役割を1つ降りる
締め：切らなくていい。全部を引き受けるのをやめるだけでいい。

## 12. 縁切りの前に、やった方がいいこと
フック：**切る作業より、残す作業の方が効く**
本体：
・残したい人を1人思い浮かべる
・今週、その人に連絡する
・いい縁に時間を使っている人のところには、消耗する縁が入り込みにくい
締め：空いた場所にしか、新しい縁は入ってこない。

## 投稿後にやること

1. コメントが付いたらエルグラムが自動DM（キーワード「縁切り」）
2. 週1で数字を見る：再生数 → コメント数 → 診断完了 → LINE登録
3. 伸びた台本は、切り口を変えて3週間後に作り直す（同じネタでいい）
4. 伸びなかった台本は捨てる。改善しない
