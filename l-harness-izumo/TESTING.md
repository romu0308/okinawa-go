# 通しテスト手順（公開前に必ず1回やる）

所要 30〜40分。自分のスマホ1台とPCでできる。

## 前提

- note 記事6本を公開済み（下書きでなく「公開」。URLが確定していること）
  ※ 合言葉のテストに購入は不要。記事URLがDay3/5/7のリンク確認に要るだけ
- `scenario.json` の `variables` に note の実URLを入れて、再シード済み
- L Harness に AI 鑑定を実装・デプロイ済み（`ANTHROPIC_API_KEY` 設定済み）
- 自分の LINE アカウントは、出雲の公式アカウントを**未登録の状態**にしておく
  （すでに友だちなら、一度ブロック→解除するか、テスト用の別アカウントを使う）

## 1. サイト → LINE（5分）

- [ ] スマホで izumo-kaiun.com を開く
- [ ] 診断を最後までやる
- [ ] 結果画面に **A / B / C / D の記号が大きく出ている**
- [ ] 「無料で詳細鑑定を受け取る」の LINE ボタンがある
- [ ] ボタンの下に「登録後に記号を送ってください」の案内がある
- [ ] サイト内に「購入」「¥」「決済」「特定商取引法」が**どこにも残っていない**
- [ ] フッター・お問い合わせに個人名・住所・電話が**残っていない**

## 2. LINE 登録 → Day0（5分）

- [ ] LINE ボタンから友だち追加できる
- [ ] LINE に「A」と送る
- [ ] 共通パート（登録ありがとう〜）が届く
- [ ] レベルAの詳細（診断結果：レベルA〜）が続けて届く
- [ ] 管理画面で自分に `level_a` `step_active` タグが付いている

## 3. ステップ配信（10分・時刻を早めて確認）

管理画面か D1 で、自分のステップ配信の「次の配信予定時刻」を直近に書き換えて、
Day1 → Day7 を順に流す。1通ずつ次を確認：

- [ ] Day1（縁を切る＝悪ではない）
- [ ] Day2 が **レベルA用の内容**（返信速度を落とす話）になっている
- [ ] Day3 の note リンクが **レベルA のレポート記事**に飛ぶ
- [ ] Day5 の note リンクがカウンセリング記事に飛ぶ
- [ ] Day7 の note リンクが講座記事に飛ぶ
- [ ] Day7 の後、タグが `step_active` → `step_done` に変わっている
- [ ] 全部の本文に `{{` が残っていない（変数の置換漏れがないか）

## 4. 合言葉 → AI 鑑定（15分）★ここが今回の目玉

**note で買う必要はない。** 合言葉はただの文字列で、購入の有無を見ていない。
あなたは合言葉を知っているので、LINE にそのまま送れば同じ動線をそのまま試せる。

- [ ] LINE に `縁A-717` と送る
- [ ] 質問3つ（①関係 ②いつから ③困っている場面）が1通で届く
- [ ] タグ `bought_report` `kantei_level_a` `kantei_waiting` が付いている
- [ ] 表記ゆれを試す：`縁A717`（ハイフンなし）／`縁ａ-717`（全角小文字）／前後に空白
      → どれも受け付ける
- [ ] 「あ」と1文字だけ送る → 「もう少し詳しく」が返る（20文字未満の判定）
- [ ] 200字くらいの状況を送る → 「受け取った」の即レスが来る
- [ ] **1〜3分以内に鑑定文が届く**
- [ ] 鑑定文が 700〜900字で、Markdown記号（#、**、-）や絵文字が入っていない
- [ ] レベルAの観点（順番・勢いで動くな）が入っている
- [ ] タグが `kantei_done` `kantei_followup_ok` に変わっている
- [ ] 追加で1回質問 → 返ってくる。2回目 → カウンセリング案内が返る
- [ ] もう一度 `縁A-717` を送る → 「鑑定は1回まで」の案内が返る（再受付しない）
- [ ] B・C・D の合言葉も1つずつ試し、**レベルごとに内容が変わる**ことを確認
      （テスト用の別 LINE アカウントか、管理画面でタグをリセットしてから）

### 合言葉を忘れた人の救済

- [ ] `鑑定` と送る → 「note の購入後エリアの一番下に合言葉がある」の案内が返る

### 安全弁のテスト（必ずやる）

- [ ] タグをリセットしてから合言葉を送り、状況欄に「殴られていて怖い」と送る
- [ ] **AI の鑑定文ではなく、相談窓口の案内**が返る
- [ ] タグ `kantei_safety_hold` が付き、`kantei_waiting` が外れている

### 合言葉の運用について（重要）

合言葉は購入を確認していないので、**知っていれば誰でも鑑定を受けられる**。
note の購入者エリアにしか書いていないので通常は漏れないが、次の運用にする。

- 3ヶ月に1回、合言葉の値を変える（`scenario.json` → 再シード → note 記事も更新）
- 1人1回までの制限はタグで効いているので、拡散しても1人1回で止まる
- 拡散が疑われたら、その時点で値を変えるだけでいい

購入と厳密に紐づけたいなら note の「購入者限定コメント」等を使う手もあるが、
1,000円の商品にそこまでの手間はかけない方がいい。
