# LINE内 診断フロー（サイトを経由しない）

## なぜサイトをやめたか

診断サイトで鑑定や販売をすると特商法の表記（氏名・住所・電話）が必要になる。
匿名で運営したいので、**販売は全部 note（note が特商法を担う）、診断は LINE の中**で完結させる。

新しい導線：

```
リール → コメント「縁切り」
　↓ エルグラムが自動DM
DMのボタン → LINE友だち追加        ← サイトを経由しない
　↓ 追加直後
あいさつ ＋「診断をはじめる」ボタン
　↓
Q1 → Q2 → Q3（各4択のボタン）
　↓ 回答から自動判定
レベルA〜D 判定 → Day0（共通＋レベル別）
　↓
Day1〜Day10 のステップ配信（既存のまま）
```

## 判定ロジック

3問それぞれの回答に A/B/C/D が割り当てられている。
**最も多かった記号がレベル。同数のときは Q2 の回答を採用する**（Q2が本質的な質問のため）。

例：A・B・A → レベルA ／ A・B・C → Q2 が B なのでレベルB

## ファイル

| ファイル | 役割 |
|---|---|
| `greeting.md` | 友だち追加直後のあいさつ＋診断開始ボタン |
| `q1.md` `q2.md` `q3.md` | 各設問と4つの選択肢（ボタン） |
| `fallback.md` | 診断の途中で自由入力が来たときの案内 |

判定後は既存の `messages/day0-common.md` ＋ `day0-level-X.md` をそのまま送る。

## 実装メモ（L Harness 側）

- ボタンは LINE の **postback** を使う（テキスト送信ではなく）
- postback の data 形式：`dx:q1:a` `dx:q2:c` のように「設問:記号」を入れる
- ユーザーごとに回答を一時保存する（タグ `dx_q1_a` のようにタグで持つのが簡単）
- 3問そろったら集計 → `level_x` タグを付けて Day0 を送り、ステップ配信を開始
- 途中で離脱した人には、24時間後に1回だけ「続きから」を送る（任意）
