# LINE のリンクをボタンにする

## なぜ必要か

LINE では、長文の中に URL を混ぜると**タップできない／されにくい**ことがある。
・行の途中に URL があると認識されないことがある
・青リンクになっても、長文の中では見落とされる
・端末やアプリのバージョンによって挙動が違う

確実にタップさせるには、**テキストとは別に「ボタン付きのメッセージ」をもう1通送る**のが正解。
これは LINE の標準機能（Flex Message）なので、どのツールでも使える。

## 送り方（2通セット）

```
1通目：本文（テキスト。URLは入れない）
2通目：ボタンだけのメッセージ ← このフォルダのJSON
```

本文からURLを消して、その代わりに「下のボタンから」と一言添える。

## ファイル

| ファイル | どのDayで使うか | ボタンの行き先 |
|---|---|---|
| `day3-report-button.json` | Day3 | `{{report_url}}`（レベル別に差し替え） |
| `day5-counseling-button.json` | Day5 | `{{counseling_url}}` |
| `day7-course-button.json` | Day7 | `{{course_url}}` |
| `day10-course-button.json` | Day10 | `{{course_url}}` |

## ツール別のやり方

### L Harness（自作ツール）の場合
JSON をそのまま LINE Messaging API の push/reply に渡す。
`{{report_url}}` などの変数は、送信前に実URLへ置換すること。
Flex Message の仕様上、`uri` に `{{...}}` が残っているとエラーになる。

### エルメ（L Message）の場合
管理画面のメッセージ編集で、テキストの下に**「ボタン」ブロック**を追加する。
JSON を貼る必要はない。次の値を入れる。

| Day | ボタンの文字 | リンク先 |
|---|---|---|
| Day3 | レポートを見る | note のレポート記事URL（レベル別） |
| Day5 | 申し込む | note のカウンセリング記事URL |
| Day7 | 講座の詳細を見る | note の講座記事URL |
| Day10 | 講座の詳細を見る | note の講座記事URL |

ボタンの文字は **20文字以内**にすること（LINEの制限）。

### どちらでも共通の注意
- ボタンは1通につき1つだけ。複数並べると押されなくなる
- 本文にもURLを残すと二重になるので、本文からは消す
- 計測したいなら、リンク先を直リンクではなくトラッキングリンクにする

## 本文からURLを消す（対応表）

| ファイル | 消す行 | 代わりに入れる行 |
|---|---|---|
| `day3-offer-report.md` | `▼レポートを受け取る（note）` と `{{report_url}}` | `▼下のボタンから受け取れる` |
| `day5-offer-counseling.md` | `▼セッションを申し込む（note）` と `{{counseling_url}}` | `▼下のボタンから申し込める` |
| `day7-offer-course.md` | `▼講座の詳細を見る（note）` と `{{course_url}}` | `▼下のボタンから詳細が見られる` |
| `day10-followup.md` | `{{course_url}}` | `▼下のボタンから詳細が見られる` |

※ この差し替えは `apply-buttons.py` で一括実行できる（下記）。
