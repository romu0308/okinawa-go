# 週1ナーチャリング配信

対象：`step_done` が付いている人（Day10 まで読み終えた人）。
頻度：週1回（水 or 木の 20:00 推奨）。月1回だけ講座に触れる。

## 型は4つ。これを回すだけでいい

| 型 | 中身 | 頻度 |
|---|---|---|
| ① 短いワーク | 5分で終わる整理の作業を1つ | 月1 |
| ② 判断基準 | 「〜な相手は残す／〜な相手は整理する」の1本 | 月1 |
| ③ 相談への回答 | 届いた相談（要約・匿名化）に答える | 月1 |
| ④ 講座案内 | ①〜③のどれかの最後に講座リンクを添える | 月1 |

同じ月に②と④を兼ねてもいい。大事なのは「4回のうち売り込みは1回だけ」。

## 書くときのルール（全型共通）

- 400〜600字。スマホで2スクロールまで
- 冒頭3行で「今日は何の話か」が分かる
- 効果の断定をしない。「〜な人が多い」「〜という見方もできる」
- 絵文字なし。Markdown記法なし。改行と「・」だけ
- 語尾は「〜だ」「〜してほしい」「〜でいい」
- 毎回、最後は「決めるのはあなたでいい」の趣旨で閉じる

## 量産の仕方

`prompts/weekly-broadcast-prompt.md` を Claude Code か Claude アプリに貼る。
1回で4本（1ヶ月分）出る。出たものを `messages/weekly/YYYY-MM.md` に保存して、
L Harness の一斉配信にコピペする。

ネタが尽きたら、`kantei_logs` テーブルから相談内容を要約させると
「実際に来ている悩み」がそのままネタになる（プロンプトに手順あり）。
