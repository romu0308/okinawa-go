# 講座の部屋（🌱出雲_縁切り講座）に貼るプロンプト

作業部屋が分かれていて、こちらの部屋は互いの会話を読めない。
そこで **GitHub のファイルを共通の正**にして、両方がそれを見る形にする。

講座の部屋で `claude` を起動し、以下を貼る。

---

出雲の縁切り講座について、別の部屋で LINE ステップ配信と note 記事を作っている。
そちらで決めた講座の正式仕様が GitHub に置いてあるので、まずそれを読んでほしい。

https://github.com/romu0308/okinawa-go/tree/claude/line-harness-scenario-setup-f5srml/l-harness-izumo/course

読むファイル：
- course/SPEC.md … 講座名・価格・章立て6つ・形式の正式仕様
- course/chapter-01-script.md … 第1章の台本（完成済み）

やってほしいこと：

1. SPEC.md を読んで、いまこの部屋で作っている講座の内容と**食い違いがないか照合**する
2. 食い違いがあれば、次の形で報告する
   - どの項目が違うか（講座名／価格／章立て／形式）
   - この部屋で決めた内容
   - なぜそう決めたか
3. 食い違いがなければ、SPEC.md に沿って作業を続ける
4. この部屋で仕様を変えたいときは、**先に SPEC.md を書き換える提案**を出す
   （LINE の Day6・Day7・Day9・Day10 と note 記事の5箇所が SPEC.md に連動しているため、
   　勝手に変えるとLINEで案内した内容と実物がズレる）

特に確認してほしいのは次の4点：
- 講座名は「出雲の縁切り実践講座」か
- 価格は 49,800円か
- 章立ては6章（①握り続ける理由 ②見分け方 ③距離の取り方 ④切れない縁 ⑤罪悪感 ⑥新しい縁の選び方）か
- 形式は「動画＋週1グループ相談会＋質問LINE」か
