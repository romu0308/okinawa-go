# 講座の部屋（🌱出雲_縁切り講座）に貼る：動画URLの確認

作業部屋どうしは会話を読めないので、必要な情報を向こうから引き出すための文面。
返ってきた内容をこちらの部屋に貼れば、SPEC.md と note 記事に反映できる。

---

出雲の縁切り講座の動画について、状況を教えてほしい。
別の部屋で LINE配信と note の販売記事を作っていて、そこに動画リンクを入れる必要がある。

次の形で答えてほしい。分からない項目は「不明」と書いてくれればいい。

【1. 進捗】
・全何章あって、いま何本アップ済みか
・アップ済みのものは YouTube に上がっているか、それとも手元にあるだけか

【2. アップ済みの動画（1本ずつ）】
章番号 / 章タイトル / YouTubeのURL / 尺（分）

【3. 公開設定の確認】
・各動画の公開設定は「限定公開」になっているか
　（「公開」だと誰でも検索で見つけられてしまうので必ず確認してほしい）
・「非公開」だと購入者が見られないので、それも困る
・正しいのは「限定公開（リンクを知っている人のみ）」

【4. 匿名性の確認】
この講座は運営者を特定されない形で出したい。次を確認して報告してほしい。
・動画内に顔が映っていないか
・地声を使っていないか（合成音声か）
・動画内・概要欄・チャンネル名・サムネイルに本名や他事業の名前が入っていないか
・アップロードに使った YouTube チャンネルは、他の事業と共有していないか
　（共有していると、チャンネルから運営者が辿られる）

【5. 章タイトルの照合】
別の部屋では、次の6章構成として LINE と note の文面を書いている。
　第1章 なぜあなたは縁を握り続けるのか
　第2章 切っていい縁・整理で済む縁の見分け方
　第3章 揉めずに距離を取る手順
　第4章 家族・職場など切れない縁との付き合い方
　第5章 離れた後の罪悪感の扱い方
　第6章 新しい縁の選び方

実際に作った動画のタイトル・内容とズレていないか照合して、
ズレていれば「実際はこうなっている」と教えてほしい。
（LINEで案内した章立てと実物が違うと、購入者との約束が食い違うため）

【6. 残作業】
まだアップしていない章があれば、何が残っていて、何が必要か
