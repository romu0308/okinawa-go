# izumo-kaiun.com（~/izumo-engiri）改修プロンプト

`~/izumo-engiri` で `claude` を起動し、画面が出てから以下を貼る。

---

このプロジェクト（izumo-kaiun.com）を「診断 → LINE誘導」だけのサイトにする。決済と特商法は撤去し、販売は全部 note に移す。加えて、運営者が特定できる情報を全部消す。

【1. Stripe と決済の完全撤去】
- Stripe 関連のコード・API ルート・Webhook・環境変数の参照・npm パッケージ（stripe, @stripe/*）を削除
- 「購入」「決済」「¥」「円」のボタン・価格表示・商品ページを全て削除する
- **このサイトはファネルから外した。** 診断は LINE の中で行うことにしたため（サイトで鑑定・販売を
  行うと特商法の表記が必要になり、匿名運営ができなくなる）。
  サイトを残す場合は「無料の読み物＋LINE誘導」だけにして、販売導線を一切置かない
- LINE 誘導ボタンを置くなら、リンク先は https://lin.ee/69dc6YF
- 決済完了ページ・サンクスページ・購入履歴などの画面があれば削除し、リンク切れが出ないようにする

【2. 特商法・運営者情報の撤去】
- 特定商取引法ページ、プライバシーポリシー内の事業者名・住所・電話、フッターの運営者表記、お問い合わせフォームの宛先表示を削除
- プライバシーポリシーは残してよいが、事業者名は「当サイト運営者」に置き換える
- サイトマップ・ナビ・フッターから該当ページへのリンクを消す

【3. 運営者特定につながる情報のスクラブ】
以下をリポジトリ全体で grep して、見つかったら削除または差し替える（結果を一覧で報告して）
- 「孔明」「koumei」「komei」「キャリア」「career」「沖縄」「okinawa」「裏」「romu」など他事業を連想させる文字列
- Google Analytics / GTM / Search Console / AdSense の ID（他サイトと共用なら新規IDに差し替える前提で、今の値を報告）
- meta author / OG / JSON-LD の author, publisher, organization の名前
- package.json の name / author / repository、README の記述
- 画像の EXIF・ファイル名に個人名や他事業名が入っていないか
- コメント内の個人名・メールアドレス

【4. 診断ページの扱い】
- 診断は LINE 内に移したので、**サイトの診断は無くても構わない**
- 残す場合：結果画面から「続きは LINE で」として https://lin.ee/69dc6YF に送るだけにする。
  結果の記号（A/B/C/D）を送らせる案内は不要（LINE 側で診断し直すため）
- 迷う場合は、診断ページごと非公開にしてよい。ファネルは LINE だけで完結する

【5. 仕上げ】
- ビルドが通ることを確認（npm run build）
- 変更したファイル一覧と、grep で見つかった特定情報の一覧を報告して
- `vercel --prod --yes` は実行せず、私が確認してから実行する
