# （任意）エルグラムの設定をブラウザ自動操作でやる場合

**基本はこれを使わなくていい。** 設定項目は7つしかないので、
`elgram/setup.md` を見ながら手で入れる方が速くて確実。

使うとしたら次のケース。

- 毎月キーワードやDM文面を差し替える運用が発生した
- 複数アカウントに同じ設定を入れる必要が出た
- 手で入れてみたが、項目が多すぎて心が折れた

## 前提

- あなたの Mac の Claude Code で動かす（ログイン状態のブラウザが必要なため）
- Playwright を使う。ログインは**あなたが手でやる**。
  ID・パスワードをプロンプトに書かない、Claude に渡さない
- エルグラムの画面構造が変わると壊れる。壊れたら手で入れる

## 手順

1. ターミナルで作業用フォルダを作る

```bash
mkdir -p ~/elgram-setup && cd ~/elgram-setup && npm init -y && npm i playwright && npx playwright install chromium
```

2. `claude` を起動して、下を貼る

---

Playwright を使って、エルグラムの管理画面の設定を半自動で入れたい。
`elgram-setup.md`（別途置く）に入れる値が全部書いてある。

作ってほしいもの：

1. `login.mjs`
   - Playwright で Chromium を **headless: false**（画面が見える状態）で起動する
   - エルグラムのログインページを開く
   - **ログインは私が手で行う**ので、ログイン完了を待つだけにする
     （URLがダッシュボードに変わるまで待つ、またはEnterキー入力を待つ）
   - ログイン後の状態を `storageState` として `auth.json` に保存する
   - `auth.json` は .gitignore に入れる

2. `setup.mjs`
   - `auth.json` を読み込んでログイン済みの状態でブラウザを開く
   - **headless: false のまま**動かす（何をしているか目で見えるように）
   - `settings.json` から設定値を読み込んで、画面に入力していく
   - 各ステップで、入力前に「今からこの項目を入れる」とコンソールに出す
   - **保存ボタンを押す直前で必ず一時停止**し、私がEnterを押したら進む
   - セレクタが見つからなかったら、その時点で止まって
     「この要素が見つからない」とスクリーンショットを保存して終了する

3. `settings.json`
   - `elgram-setup.md` の値を構造化したもの
   - キーワード、公開返信5パターン、DM1通目、DM2通目、各種フラグ

重要な制約：
- ID・パスワードをコードにもファイルにも書かない。ログインは必ず手動
- 削除系の操作（既存ルールの削除など）は絶対に自動化しない。追加と編集だけ
- 想定外の画面が出たら、推測で進めずに止まる
- `--dry-run` フラグを付けたら、入力だけして保存を押さないモードにする

まず `login.mjs` だけ作って、私が実際にログインできるか試すところから始めて。

---

## やらないこと

- 投稿・コメント・DMの**送信**は自動化しない。設定だけにする
- Instagram 本体の操作は自動化しない（アカウント制限のリスクがある）
- ログイン情報の保存先（`auth.json`）は絶対にリポジトリに入れない
