# 週1配信 量産プロンプト（1回で1ヶ月分）

Claude Code（`~/line-harness`）か Claude アプリに貼る。
`kantei_logs` から実際の相談を材料にする場合は、先に手順Aを実行する。

---

## 手順A（任意・実際の相談をネタにする場合のみ）

`~/line-harness` の Claude Code で先にこれを実行：

```
D1 の kantei_logs テーブルから直近30日分の input カラムを取得して、
個人が特定できる情報（名前・地名・会社名）を全部伏せたうえで、
相談内容を10個の類型に要約して。多い順に並べて、各類型に件数を付けて。
```

出てきた要約を、下のプロンプトの「■ 今月のネタ」に貼る。

---

## 本体プロンプト

あなたは「出雲の縁切り」というLINE公式アカウントの配信を書く担当です。
読者は人間関係で消耗し、7日間のステップ配信を読み終えた人たちです。
すでに一度は講座の案内を受けていて、買わなかった人が中心です。

来月分の週1配信を4本書いてください。

■ 4本の型（この順で1本ずつ）
1週目：短いワーク（紙とペンで5分で終わる、人間関係の整理の作業を1つ）
2週目：判断基準（「こういう相手は残す／こういう相手は整理する」を1つの軸で）
3週目：相談への回答（下の「今月のネタ」から1つ選び、匿名化したまま答える）
4週目：3週目までのどれかを受けて、最後に講座リンクを1行だけ添える

■ 文体
・一人称は「私」、二人称は「あなた」
・語尾は「〜だ」「〜してほしい」「〜でいい」。敬語は使わない。ただし突き放さない
・「〜なんよ」「〜やん」などの方言・キャラ語尾は使わない
・絵文字・顔文字・Markdown記法（#、**、-、番号付きリスト）は使わない。改行と「・」だけ
・1文は短く。1段落3行以内。段落の間は空行
・1本 400〜600字

■ 内容のルール
・効果を断定しない。「縁が切れる」「必ず楽になる」と書かない
・相手を悪者にして煽らない。「いい人だけど合わない」は普通に存在する、という立場
・占い・スピリチュアル・宗教の言い回しを使わない。人間関係の整理の手順として書く
・毎回、最後は「決めるのはあなたでいい」の趣旨で閉じる
・売り込みは4週目の1行だけ。1〜3週目は完全に無料の価値提供にする

■ 今月のネタ
（手順Aの要約を貼る。なければ「特になし」と書く。その場合は一般的な相談類型から選んでよい）

■ 出力形式
4本を、それぞれ「## 1週目」「## 2週目」…の見出しで区切って出力。
見出しの下は、LINEにそのまま貼れる本文だけ。解説や補足は書かない。
