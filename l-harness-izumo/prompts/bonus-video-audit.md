# 既存 LINE 特典動画・講座の再配置プロンプト

いま持っている特典動画・過去講座を、新しいファネル（note一本化）のどこに置くか決めるためのもの。
**`assets/bonus-videos.csv` を埋めてから**、下のプロンプトを Claude Code か Claude アプリに貼る。

## 手順1：棚卸し表を埋める

`assets/bonus-videos.csv` を開いて、持っている動画・PDF・音声を1行ずつ書く。

| 列 | 書くこと |
|---|---|
| title | 動画のタイトル |
| length_min | 長さ（分）。PDFなら空欄 |
| current_price | 無料 / 1000 / 4980 など、いま付いている価格 |
| current_place | LINE特典 / 旧note / 旧講座 / 未公開 |
| quality | 高 / 中 / 低（今の目で見て人に見せられるか） |
| new_place | 空欄でよい（プロンプトが埋める） |
| note | 補足（例：顔出しあり、他事業の名前が入っている、など） |

**重要**：他事業（キャリア孔明など）の名前・URL・顔・声が入っている動画は
`note` 列に必ず書く。そのまま使うと匿名運営が崩れる。

## 手順2：プロンプトを貼る

---

添付の bonus-videos.csv は、私が既に持っている特典動画・過去講座の一覧です。
これを「出雲の縁切り」の新しいファネルに再配置してください。

■ 新しいファネルの構造
- LINE ステップ配信 Day0〜7（無料の価値提供 → note へ誘導）
  - Day0：診断結果の受け止め（レベル別）
  - Day1：縁を切る＝悪ではない
  - Day2：最初の一歩（レベル別）
  - Day3：note 1,000円 レベル別レポートの案内
  - Day4：よくある相談パターン
  - Day5：note 4,980円 カウンセリングの案内
  - Day6：講座の中身公開
  - Day7：note 49,800円 講座の案内
- Day8〜10：買わなかった人向けフォロー
- 週1ナーチャリング配信（無料・ずっと続く）
- note 有料記事：レポート4本（1,000円）／カウンセリング（4,980円）／講座（49,800円）
- 講座は6章構成：①なぜ握り続けるのか ②切る縁と整理で済む縁の見分け方 ③揉めずに距離を取る手順 ④切れない縁との付き合い方 ⑤罪悪感の扱い方 ⑥新しい縁の選び方

■ 配置のルール
1. 無料だったもの → Day0〜2 の補強、または週1配信のネタにする
2. 有料だったもの → note 有料記事に移す。単発は 1,000〜4,980円帯、まとまったものは講座の「章」として吸収する
3. LINE 内で決済に触れない。LINE からは note のリンクを送るだけ
4. quality が「低」のものは、作り直す前提で「保留」にする
5. note 列に他事業の名前・顔・声への言及があるものは、**必ず「要撮り直し」**にする。匿名運営が最優先

■ 出力してほしいもの
1. 配置表（title / 新しい置き場所 / 理由 / 作業の要否）をマークダウンの表で
2. 講座6章のうち、既存素材で埋まる章と、新規収録が必要な章の一覧
3. 「今すぐ使えるもの」「手直しすれば使えるもの」「捨てるべきもの」の3分類
4. 新規収録が必要な動画の、優先順位付きリスト（先に売って後から作る方針なので、第1章から順に）

配置表の new_place 列を埋めた CSV も出力してください。
