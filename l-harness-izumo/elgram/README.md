# エルグラム設定パッケージ

## 先に正直なところ

**エルグラムの管理画面を私が直接操作することはできない。** 理由は2つ。

1. この作業環境から外部サイトへの接続が遮断されている（izumo-kaiun.com すら開けなかった）
2. あなたのエルグラム／Instagram のログイン情報を私は持っていないし、預かるべきでもない

確認した結果（2026-09-04）：

```
go.lgram.jp:443   → 403 policy denial
lgram.jp:443      → 403 policy denial
www.instagram.com → 403 policy denial
```

なので、**あなたのMacで動く自動化ツール一式を完成品として用意した。**
あなたがやるのはログインだけで、設定の入力は自動で入る。

| | 中身 | 所要 |
|---|---|---|
| ① `automation/` | **Macで動かす自動化ツール。ログインだけ手動、あとは自動** | 準備込み30分 |
| ② `setup.md` | 手で入れる場合の設定表。全項目の入力値と文面 | 20〜30分 |

①がうまく動かなかったときは②に切り替えればいい。入る値は同じ。
文面を直したいときは `automation/settings.json` を直して再実行するだけ。

## 設定の全体像（これだけ）

```
リールのコメントに「縁切り」
　↓ エルグラムが検知
　├ コメントに公開返信（5パターンをローテーション）
　└ DMを1通送る ← 診断URLはここに入れる
　　　↓ 相手が何か返信する（＝24時間の会話枠が開く）
　　　└ フォローDM 1通（LINE登録の後押し）
```

## Instagram の仕様で、これだけは知っておく

- コメントへの自動DM（プライベートリプライ）は **1通しか送れない**。
  だから1通目に診断URLを必ず入れる。「後で送ります」は届かない
- 相手が1度でも返信すると、そこから **24時間だけ**追加DMを送れる。
  なので1通目の最後に「受け取れたら『はい』と返して」を必ず入れる
- 24時間を過ぎると、こちらからは送れない。追いかけない
- Instagram のアカウントは **プロアカウント（ビジネス）** かつ Facebook ページ連携が必須

## 設定する順番

1. `setup.md` の「事前確認」を上から潰す
2. キーワード応答を1本だけ作る（縁切り）
3. 自分の別アカウントでリールにコメントして、DMが届くか試す
4. 届いたらリール投稿を始める

## 匿名運営の注意（Instagram 側）

- Instagram は出雲専用アカウント。他事業のアカウントと相互フォローしない
- 「おすすめアカウント」に出るのを避けるため、連絡先の同期をオフにする
- プロフィールのメールアドレス・電話番号は表示しない設定にする
- 同じ端末で複数アカウントを切り替えると関連付けが起きやすい。
  可能なら出雲用はブラウザ版か別端末で運用する
