# エルグラム 設定表（この通りに入れれば完了）

画面のメニュー名はバージョンで変わることがある。
名前が違ったら、**役割が同じ項目**を選べばいい（例：「キーワード応答」＝「自動応答」「コメント返信」）。
迷ったら画面のスクリーンショットを私に貼ってくれれば、どこを触るか指示する。

---

## 0. 事前確認（ここが済んでいないと動かない）

- [ ] Instagram が**プロアカウント**（ビジネスまたはクリエイター）になっている
- [ ] Instagram と Facebook ページが連携済み
- [ ] エルグラムに Instagram アカウントを接続済み
- [ ] Instagram の設定 →「メッセージとストーリーズへの返信」で、
      **ビジネスアカウントからのメッセージ受信を許可**している
- [ ] 診断URL（https://www.izumo-kaiun.com/ の診断ページ）が公開されている

## 1. キーワード応答（作るのは1本だけ）

| 項目 | 入れる値 |
|---|---|
| ルール名 | 縁切り診断DM |
| 対象 | 投稿・リールへのコメント |
| 対象の投稿 | すべての投稿（新しい投稿にも自動適用） |
| キーワード | `縁切り` |
| 一致方法 | 部分一致（「縁切り診断」「縁切りお願いします」も拾う） |
| 大文字小文字・全角半角 | 区別しない |
| 同一ユーザーへの再送 | しない（1人1回） |
| 自分のコメントを除外 | する |

**キーワードは「縁切り」1つに統一する。** 増やすと、どのリールが効いたか分からなくなる。

### 誤爆対策

次の言葉が入っているコメントは反応しない設定にする（除外キーワード）。
入力欄がなければ、届いたDMを週1で見て手動で対応すればいい。

```
縁切りたくない
縁切り神社
縁切り寺
```

## 2. コメントへの公開返信（5パターンをローテーション）

同じ返信を連投するとスパム判定を受けやすい。5つ登録して順番に使う。

```
1: 送ったよ🕊
2: DMに送った。確認してみて。
3: 送っておいた🕊
4: DM見てみて。
5: 送った。届いてなかったら教えて。
```

絵文字を毎回入れない。3つに1つくらいでいい。

---

## 3. 自動DM（1通目）★ここに診断URLを入れる

プライベートリプライは1通しか送れない。この1通で完結させる。

```
コメントありがとう🕊

縁切り診断はこちら。
1分で終わる。

https://www.izumo-kaiun.com/

診断すると、あなたが
・今すぐ離れたい相手がいるタイプ
・離れたいけど迷ってるタイプ
・誰のせいか分からないタイプ
・今は落ち着いてるタイプ
のどれかが出る。

結果に合わせて、
縁の整理の順番を送ってる。

受け取れたら「はい」とだけ返してほしい。
続きを送るね。
```

**最後の1行を消さないこと。** 相手が返信して初めて、こちらから追加のDMを送れるようになる。

## 4. 自動DM（2通目・返信が来たら）

| 項目 | 入れる値 |
|---|---|
| トリガー | DMを受信したとき（1通目送信済みの人） |
| キーワード | 指定なし（何を返してきても発火） |
| 送信タイミング | 即時 |

```
ありがとう。

診断、もうやってみた？

結果画面の一番下に
「無料で詳細鑑定を受け取る」ってボタンがある。

そこから LINE に登録すると、
診断結果に合わせた詳しい鑑定を
翌朝8時に送ってる。

7日間、縁の整理の手順を順番に届けるので
読むだけでいい。

https://www.izumo-kaiun.com/
```

## 5. ストーリーズへの反応（任意・後回しでいい）

| 項目 | 入れる値 |
|---|---|
| トリガー | ストーリーズへのリプライ |
| キーワード | `縁切り` |
| 返信 | 1通目と同じ文面 |

ストーリーズで「診断作った。『縁切り』って送って」と流すと、
リールより濃い人が来る。フォロワーが増えてから設定すればいい。

## 6. タグ（エルグラム側）

数字を見るために最低限これだけ付ける。

| タグ名 | 付ける条件 |
|---|---|
| 縁切りDM送信済 | 1通目を送ったとき |
| DM返信あり | 相手から返信が来たとき |

エルグラムでは「診断をやったか」「LINEに登録したか」までは追えない。
そこから先は L Harness 側で見る。

## 7. テスト（必ずやる）

- [ ] 自分の別アカウント（または知人）でリールに「縁切り」とコメント
- [ ] コメントに公開返信が付く
- [ ] DMが1通届く
- [ ] DM内のURLをタップして診断ページが開く
- [ ] DMに「はい」と返す
- [ ] 2通目が届く

## 数字の見方（週1回）

| 見る数字 | どこで | 目安 |
|---|---|---|
| リール再生数 | Instagram | — |
| コメント数 | Instagram | 再生の 0.5〜2% |
| DM送信数 | エルグラム | コメント数とほぼ同じなら正常 |
| DM返信率 | エルグラム | 30%以上あれば良い |
| LINE登録数 | L Harness | **これが本命の数字** |

DM送信数がコメント数より明らかに少ない → キーワード設定か Instagram の受信設定を疑う。
DMは届いているのに LINE 登録が伸びない → 診断ページか結果画面のボタンを疑う。
