# エルグラム が動かないときの切り分け

上から順に見る。ほとんどは①〜③のどれか。

## ① DMが1通も届かない

| 確認 | 直し方 |
|---|---|
| Instagram がプロアカウントか | 個人アカウントだと自動DMは動かない。設定 → アカウントの種類 → プロアカウントに切り替え |
| Facebook ページと連携しているか | 連携が切れると無言で止まる。エルグラム側で再接続 |
| エルグラムの接続が期限切れでないか | Instagram のトークンは定期的に切れる。管理画面に警告が出ていないか確認 |
| ルールが「有効」になっているか | 作っただけで有効化を忘れているケースが多い |
| 対象の投稿に、その投稿が含まれているか | 「すべての投稿」にしていないと、新しいリールが対象外になる |

## ② コメントは拾うのにDMが届かない

- 相手が **ビジネスアカウントからのメッセージを拒否**している。これはこちらでは直せない。
  公開返信に「DM届かない人は、プロフィールのリンクから診断できる」と1文入れておくと拾える
- 相手がこちらをフォローしていない状態でも届くはずだが、
  相手側の「メッセージリクエスト」フォルダに入っていることがある。届いていないわけではない

## ③ DMにボタンが出ない・URLがタップできない

- 本文にURLを書いていないか確認する。**URLはボタンブロックにだけ入れる**
- ボタンの文字が20文字を超えていないか（超えると保存できない、または表示が崩れる）
- ボタンは1通に1つだけ。複数入れると押されにくくなる

## ④ 同じ人に何度もDMが飛ぶ

- 「同一ユーザーへの再送」を「しない」にする
- 一致方法が「部分一致」だと、その人の別のコメントにも反応する。それでも1人1回設定なら止まる

## ⑤ 関係ないコメントに反応する

- 除外キーワードに `縁切りたくない` `縁切り神社` `縁切り寺` を入れる
- それでも誤爆するなら、一致方法を「完全一致」に変える。
  ただし拾える数はかなり減る。誤爆1割くらいは許容した方が総取得数は増える

## ⑥ アカウントに制限がかかった

同じ文面を短時間に大量送信すると Instagram 側で制限がかかる。

- 公開返信は必ず5パターン以上をローテーション
- 1日のDM送信上限をエルグラム側で設定できるなら 50〜100 に抑える
- 制限が出たら24〜48時間、自動応答を止めて様子を見る

## ⑦ 数字が合わない

| 症状 | 疑うところ |
|---|---|
| コメント数 >> DM送信数 | キーワード設定、除外キーワード、投稿の対象範囲 |
| DM送信数 >> LINE登録が少ない | 本文が長すぎてボタンまで読まれていない。または本文にURLを二重に書いている |
| LINE登録は多いが診断が完了しない | 友だち追加時のあいさつ・診断ボタンが出ていない（L Harness側） |

最後のものはエルグラムではなく LINE 側の問題。`messages/diagnosis/` の設定を確認する。

## 判断に迷ったら

管理画面のスクリーンショットを貼ってくれれば、どこを触るか具体的に指示する。
エルグラムのバージョンによって項目名が違うので、実物を見た方が早い。
