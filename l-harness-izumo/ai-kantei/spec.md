# AI 個別鑑定 自動返信 仕様（L Harness 拡張）

旧運用: 有料note → 購入者が LINE にキーワードと状況を送る → 人が手で鑑定を書いて返す
新運用: 同じ入口のまま、返信を Claude API で自動生成する。人の作業ゼロ。

## 1. 利用者から見た流れ

1. note でレベル別レポート（1,000円）を購入
2. 購入者限定エリアの末尾にある合言葉（レベル別）を LINE に送る
3. LINE から質問が1通届く（3つの質問を1通にまとめたもの）
4. 状況を1通で返す
5. 1〜2分以内に個別鑑定（700〜900字）が届く
6. 追加で1回だけ質問できる。2回目以降は「カウンセリングで」と案内

## 2. 合言葉

| レベル | 合言葉 | 付けるタグ |
|---|---|---|
| A | `縁A-717` | bought_report, kantei_level_a |
| B | `縁B-323` | bought_report, kantei_level_b |
| C | `縁C-505` | bought_report, kantei_level_c |
| D | `縁D-141` | bought_report, kantei_level_d |

**照合は寛容にする。** 購入者が打ち間違えて弾かれるのが一番の機会損失なので、
次の正規化をしてから比較する。

1. 前後の空白・改行を除去
2. 全角英数字・全角ハイフン → 半角に変換
3. 英字を大文字に統一
4. ハイフン・スペース・アンダースコアを全部除去

この結果、次はすべて `縁A-717` として受け付ける：
`縁A-717` / `縁A717` / `縁ａ-717` / `縁 A 717` / `　縁A－717　` / `縁a_717`

- 同一ユーザーが同じ合言葉を2回送っても再受付しない（`kantei_done` タグがあれば「鑑定は1回まで」の案内）
- 合言葉は `scenario.json` の `ai_kantei.passcodes` で管理。3ヶ月に1回値を変え、note 記事も同時に更新する
- **購入は確認していない**（合言葉を知っていれば通る）。1人1回の制限がタグで効いているので、
  拡散しても被害は限定的。厳密に紐づける実装は 1,000円の商品には見合わない

## 2-2. 合言葉を忘れた人の救済

`鑑定` `合言葉` `パスワード` のいずれかを送った人には、次を返す（タグは付けない）。

```
合言葉は、購入した note の記事の一番下にある。

「ここから先は購入者のみ」の下まで
スクロールしてほしい。
一番下に「縁◯-◯◯◯」という形で書いてある。

見つからなければ、購入したときの
noteのアカウントでログインし直すと表示される。
```

## 3. 状態遷移（タグで管理）

```
[合言葉受信] → +bought_report, +kantei_level_X, +kantei_waiting
             → 送信: intake メッセージ（下記）
[kantei_waiting の人から自由文受信]
   ├ 危険ワード検知 → 送信: safety メッセージ, -kantei_waiting, +kantei_safety_hold（AIは呼ばない）
   ├ 20文字未満 → 送信: 「もう少し詳しく」（状態そのまま）
   └ 通常 → Claude API 呼び出し → 送信: 鑑定文, -kantei_waiting, +kantei_done, +kantei_followup_ok
[kantei_followup_ok の人から自由文受信]
   → Claude API（前回の入出力を履歴として渡す）→ 送信, -kantei_followup_ok
[それ以外の自由文] → 既存の挙動（何もしない or 既定応答）
```

## 4. メッセージ

### intake（合言葉受信直後）
```
合言葉、確認した。

ここから先は、あなたの状況に合わせて視る。
次の3つを、1通にまとめて送ってほしい。

①その相手との関係（例：職場の先輩、10年来の友人、母親）
②いつから、どんなふうにしんどいか
③いま一番困っている場面をひとつ

長くなっても構わない。書けた分だけでいい。
送ってもらってから、数分で返す。
```

### short（20文字未満）
```
もう少しだけ詳しく教えてほしい。
①関係 ②いつから ③一番困っている場面
この3つが分かると、ちゃんと視られる。
```

### safety（危険ワード検知）
```
送ってくれてありがとう。

いま書いてくれた内容は、
LINEの鑑定で扱っていいものを超えている。
ここで軽く返すのは、あなたに対して不誠実だと思う。

身の危険や、自分を傷つけたい気持ちがあるなら
まずここに連絡してほしい。

・よりそいホットライン 0120-279-338（24時間）
・DV相談ナビ #8008
・警察相談専用 #9110

落ち着いてから、また連絡してくれればいい。
この LINE はいつでも開いている。
```

危険ワード（部分一致・例）: 死にたい, 消えたい, 自殺, 殴られ, 暴力, 監禁, 脅され, 殺す, ストーカー, 逃げられない

### followup_end（追加質問を使い切った後の自由文）
```
ここから先は、文字だけで返すには
あなたの状況が個別すぎる。

もし本気で整理したいなら
個別カウンセリング（4,980円）で
一緒に順番を決める時間をとっている。
{{counseling_url}}

もちろん、配信を読み続けるだけでもいい。
```

## 5. Claude API 呼び出し

- SDK: `@anthropic-ai/sdk`（Cloudflare Workers で動く）
- モデル: `claude-opus-5`（思考は既定で有効。`thinking` は指定しない）
- `max_tokens: 4000`、`output_config: { effort: "medium" }`
- `system`: `system-prompt.md` の共通部 ＋ レベル別の追記（`cache_control` を付けて固定）
- `messages`: 初回は利用者の入力1通。追加質問時は [初回入力, 初回鑑定, 追加質問] の3通
- 出力はプレーンテキスト。Markdown 記法（#, **, -）を使わないよう system で指示
- 失敗時（例外・`stop_reason: "refusal"`）: 「いま鑑定がうまく出せなかった。少し時間をおいてもう一度、同じ内容を送ってほしい」と返し、`kantei_waiting` は維持
- 応答は 1〜2分かかりうるので、Worker では `ctx.waitUntil()` で非同期に生成し、LINE Push API で送る（Reply token の有効期限内に返そうとしない）
- API キーは Worker の secret（`ANTHROPIC_API_KEY`）。コードやリポジトリに置かない

## 6. ログ・コスト

- D1 に `kantei_logs(user_id, level, input, output, tokens_in, tokens_out, created_at)` を残す（後で文面改善に使う）
- 1鑑定あたり入力 ~2K・出力 ~1.5K トークン想定。1件 10〜30円程度。1,000円の商品に対して無視できる
- 週次で `kantei_logs` から「よく出る相談パターン」を Claude Code に要約させ、Day4 やナーチャリング文面の材料にする
