# 出雲縁切り 事業設計（note一本化・完全自動化・匿名運営 版）

最終更新: 2026-09-03

## 0. 結論（この設計で何が変わるか）

| 項目 | 旧 | 新 |
|---|---|---|
| 決済 | Stripe（特商法表記が必要） | **note のみ**（特商法表記は note が担う） |
| 1,000円 鑑定書 | 有料note → LINEで手動鑑定 | 有料note（レベル別4本）＋ **LINEで合言葉→AIが自動鑑定** |
| 4,980円 カウンセリング | Stripe | note 有料記事（申込チケット） |
| 49,800円 講座 | Stripe / LP | note 有料記事（無料エリア＝LP、購入者エリア＝動画） |
| サイト izumo-kaiun.com | 診断＋Stripe決済 | **診断＋LINE誘導のみ**。決済・特商法ページは撤去 |
| 運営者情報 | — | どこにも個人名・住所・キャリア孔明との接点を出さない |

売る場所は note だけ。LINE は「育てて note に送る」役。サイトは「診断で LINE に送る」役。
役割を1つずつにすると、特商法・決済・返金の面倒が全部 note に寄る。

## 1. ファネル全体（確定）

```
Instagramリール（縁切りあるある）
  ↓ コメント「縁切り」
エルグラム自動DM → izumo-kaiun.com の縁切り診断
  ↓ 結果画面「LINEで詳細を受け取る」→ LINE登録 → A〜D を送信
  ↓
LINE ステップ配信 Day0〜7（L Harness、全自動）
  Day3 → note 1,000円 レベル別診断レポート（4本）
           └ 購入者エリアの合言葉を LINE に送る → AI が個別鑑定を自動返信
  Day5 → note 4,980円 カウンセリング申込チケット
  Day7 → note 49,800円 講座
  ↓ 買わなかった人
週1配信（AI下書き）＋月1で講座再案内
```

## 2. 商品と note の作り

| 商品 | note の形 | 無料エリア | 購入者限定エリア |
|---|---|---|---|
| レポート 1,000円 ×4 | 有料記事 | レベルの説明＋「この記事で分かること」 | 3章の本文 ＋ **LINE用の合言葉**（AI個別鑑定の鍵） |
| カウンセリング 4,980円 | 有料記事 | 何をする時間か・向く人向かない人 | 予約カレンダーURL ＋「LINEに『申込みました』と送る」 |
| 講座 49,800円 | 有料記事（noteプレミアム必須） | 講座LP（目次・対象・形式・価格） | 動画リンク（YouTube限定公開）＋週1相談Zoom＋質問用LINE |

本文の下書きは `note/` に全部入っている。

### 既存の LINE 特典動画・講座の扱い（再設計ルール）
- **無料で配っていたもの** → Day0〜2 の価値提供に組み込む（登録直後の「診断結果」の次に渡す）か、Day8 以降の週1配信のネタにする
- **有料だったもの** → 全部 note 有料記事に移す。単発は 1,000〜4,980円帯、まとまったものは講座の「章」として吸収する
- LINE 内で決済に触れない。LINE は常に「note のリンクを送るだけ」
- 特典動画の一覧（タイトル・長さ・有料/無料）があれば、各 Day / note 記事への割り当て表を作る

## 3. 自動化の設計（人が対応する箇所をゼロにする）

| 工程 | 担当 | 状態 |
|---|---|---|
| 診断 → LINE 誘導 | izumo-kaiun.com | 済（Stripe撤去のみ必要） |
| A〜D 受付・ステップ配信 | L Harness | `scenario.json` を投入すれば済 |
| 1,000円 レポート販売 | note | 記事4本を公開すれば済 |
| **個別鑑定の返信** | **L Harness ＋ Claude API** | `ai-kantei/` の仕様どおり実装（旧: 手動） |
| カウンセリング予約 | note ＋ 予約カレンダー | 自動（実施だけ人） |
| 講座の動画配信 | note 購入者エリア | 記事更新のみ |
| 週1配信の下書き | Claude Code | プロンプト1本で量産 |

**個別鑑定の自動化（旧: 手動で一番面倒だった部分）**
1. note 購入者エリアに合言葉（例 `縁-A-7`）を書いておく
2. 利用者が LINE に合言葉を送る → L Harness が `bought_report` タグ付け → 質問3つを1通で返す
3. 利用者が状況を送る → L Harness が Claude API を呼び、レベル別のシステムプロンプトで鑑定文を生成 → そのまま返信
4. 1購入につき鑑定1回＋追加質問1回まで（タグで制御）。合言葉の使い回しは購入者ID単位で1回まで
5. 危険ワード（自傷・DV等）は AI を通さず定型の相談窓口案内に切り替える

詳細は `ai-kantei/spec.md`、生成プロンプトは `ai-kantei/system-prompt.md`、参考実装は `ai-kantei/worker-reference.ts`。

## 4. 匿名運営チェックリスト（キャリア孔明と絶対に紐づけない）

**アカウント・インフラ**
- [ ] note は新規アカウント。登録メール・ユーザー名・プロフィール画像は他事業と共有しない
- [ ] note の振込口座・本人確認は note 内部のみで非公開だが、**表示名・URL スラッグに本名や既存ハンドルを使わない**
- [ ] LINE 公式アカウントは出雲専用（済）。プロフィールに他事業のリンクを置かない
- [ ] Instagram も専用。同じ端末でも別アカウント。相互フォロー・ストーリー共有をしない
- [ ] ドメイン: WHOIS 代行が有効か確認。DNS を他事業と同じ Cloudflare アカウントで持つ場合、公開情報には出ないが **Vercel/Cloudflare のチーム名・プロジェクト名に「koumei」等が入っていないか**確認
- [ ] Google Analytics / GTM / Search Console のプロパティは新規作成。**同じ GA 測定IDや AdSense ID を使い回すと、外部ツールで同一運営者と特定される**
- [ ] favicon・OG画像・素材写真を他サイトと共有しない
- [ ] **GitHub: `okinawa-go` は公開リポジトリ。このフォルダ（l-harness-izumo）が入ったブランチを main にマージしない。ローカルへの取り込みが終わったらブランチごと削除する。**恒久的に置くなら非公開リポジトリへ移す
- [ ] izumo-engiri / line-harness のリポジトリを GitHub に置くなら **非公開**にする

**コンテンツ**
- [ ] 文体の指紋: 「〜なんよ」「〜だ。」調が他事業と同じなら、出雲は語尾・一人称・記号（🕊など）を変えて別人格にする。今の LINE 文面は語尾を要確認
- [ ] 顔・声を出さない。動画はスライド＋合成音声 or テキスト
- [ ] 「私は他にも〜をやっていて」等の自己言及を全文面から排除
- [ ] 実績・肩書・出身・年齢など、照合できる属性を書かない
- [ ] note 記事内・LINE 内・サイト内に他事業の URL / 商品名 / ハンドルを一切置かない
- [ ] 特商法ページ・運営者情報ページはサイトから撤去（note で売るので不要）

**法務（匿名でも守る）**
- 効果の断定なし。「縁が切れる」と約束しない
- ウソの締切・限定なし
- note の禁止事項（占い的効果の標榜・宗教勧誘）に触れない。「人間関係の整理の手順」として書く
