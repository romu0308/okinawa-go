# 第1章 なぜあなたは縁を握り続けるのか（台本・約15分）

顔出しなし。スライド＋合成音声。
左が画面に出す文字、右が読み上げ。**画面の文字は読み上げの要約であって、全文ではない。**

---

## 00:00 導入（1分）

**画面**
```
第1章
なぜあなたは縁を握り続けるのか
```

**読み**
出雲の縁切り実践講座、第1章を始める。
この章でやるのは、切る練習じゃない。
あなたがなぜ切れずにいるのか、その理由を特定する作業だ。

順番が逆に見えるかもしれない。
でも、理由が分からないまま切ろうとすると、必ず途中で戻る。
戻る人の共通点は、切る技術がなかったことじゃない。
自分がなぜ握っているのかを知らないまま動いたことだ。

15分ある。紙とペンを用意してほしい。

---

## 01:00 前提をひとつ（1分30秒）

**画面**
```
握り続けているのは
意志が弱いからではない
```

**読み**
最初に、これだけは言っておく。

あなたが縁を切れずにいるのは、意志が弱いからじゃない。
決断力がないからでもない。

切れない人には、切れないだけの理由がちゃんとある。
そしてその理由は、たいていあなたの美点の裏返しだ。

義理を大切にする人ほど、役目を終えた縁を抱え続ける。
人の痛みが分かる人ほど、相手の落胆を先に想像してしまう。
真面目な人ほど、「途中で投げ出した自分」を許せない。

この章では、その理由に名前をつける。
名前がつくと、扱えるようになる。

---

## 02:30 3つの理由（5分）

**画面**
```
縁を握り続ける3つの理由

① 恩
② 場
③ 自己像
```

**読み**
縁を握り続ける理由は、大きく3つに分かれる。
順番に説明する。自分がどれに当てはまるか、聞きながら考えてほしい。

---

**画面**
```
① 恩
「あのとき助けてもらったから」
```

**読み**
ひとつめは、恩だ。

昔、助けてもらった。困っているときに話を聞いてくれた。
仕事を紹介してもらった。落ち込んでいるときにそばにいてくれた。

その記憶があると、いま消耗していても、それを口にできなくなる。
「あれだけしてもらっておいて、いまさら距離を置くなんて」と思う。

ここで大事なのは、恩には**有効期限がない代わりに、返済の形は選べる**ということだ。
恩を感じることと、いまの関係を続けることは、別の話にできる。

もうひとつ。
恩を理由に関係を続けさせようとしてくる相手がいたら、それは恩じゃなく貸しだ。
本当の恩は、返せと言ってこない。

---

**画面**
```
② 場
「切ったら、周りに何を言われるか」
```

**読み**
ふたつめは、場だ。

共通の友人がいる。同じ職場にいる。同じコミュニティにいる。
切ったら、その場にいられなくなるかもしれない。
何を言われるか分からない。

これは現実的な不安で、無視していいものじゃない。
実際、切り方を間違えると、その場を失うことがある。

だからこの講座では、第3章で「揉めない切り方」を扱う。
順番を守れば、場を失わずに距離だけ取れることが多い。

いまの時点で覚えておいてほしいのは、
**場が理由なら、切る必要はないかもしれない**ということだ。
消耗を減らすだけで解決する場合がある。

---

**画面**
```
③ 自己像
「切ったら、冷たい人間になる気がする」
```

**読み**
みっつめが、いちばん厄介だ。自己像。

切ることそのものより、切った自分を受け入れられない。
「私は人を大切にする人間でありたい」という自己像があって、
縁を切る行為が、それと矛盾するように感じる。

これは相手の問題じゃなく、完全にあなたの中の問題だ。
だから相手が変わっても解決しない。

ここで、ひとつ考え方を渡す。

合わない縁を握ったまま、中途半端に接し続けること。
連絡が来ても気が重い、会っても上の空、返事が遅れて申し訳なく思う。
これは、相手に対して誠実だろうか。

私はそうは思わない。
**握り続けることの方が、相手にも自分にも不誠実になる場面がある。**

切るのは、冷たさじゃない。
自分の時間を、誰に使うかを決めることだ。

## 07:30 ワーク（4分）

**画面**
```
ワーク
紙に3つ書く
```

**読み**
ここからワークだ。動画を止めてやってもいいし、聞きながら書いてもいい。

紙を1枚用意する。

**画面**
```
1. いま距離を取りたい相手を1人
（名前でも、関係性でもいい）
```

**読み**
まず、いま距離を取りたい相手を1人だけ書く。
名前を書くのに抵抗があれば、「職場の先輩」でも「学生時代の友人」でもいい。

1人に絞るのが大事だ。複数書くと、どれも進まない。

**画面**
```
2. 切れない理由は
① 恩  ② 場  ③ 自己像
どれか（複数可）
```

**読み**
次に、その相手を切れない理由が、さっきの3つのどれかを書く。
複数でもいい。だいたい2つ重なっている人が多い。

**画面**
```
3. その理由に、
反論を1行書く
```

**読み**
最後に、その理由に対する反論を1行書く。

たとえば、
「恩がある」に対しては「恩を感じることと、会い続けることは別」。
「場を失う」に対しては「距離を取るだけなら、場は失わない」。
「冷たい人間になる」に対しては「中途半端に接する方が不誠実」。

自分の言葉でいい。うまくまとまらなくてもいい。
書いた瞬間に、握っていた手が少しゆるむ。

## 11:30 やってはいけないこと（2分）

**画面**
```
この段階でやってはいけない

・相手に宣言する
・共通の知人に相談する
・SNSでほのめかす
```

**読み**
ここで、やってはいけないことを3つ言っておく。

ひとつめ。相手に「距離を置きたい」と宣言すること。
まだ早い。宣言すると相手が動く。動かれると、あなたのペースが崩れる。

ふたつめ。共通の知人に相談すること。
高い確率で伝わる。伝わったときに、あなたが悪者になる。

みっつめ。SNSでほのめかすこと。
言うまでもないが、いちばん揉める。

いま必要なのは、**あなたの中で理由がはっきりすること**だけだ。
外に出すのは、第3章の手順を知ってからでいい。

```
今週の一歩

```

そのとき、紙に書いた反論を思い出してほしい。

それだけでいい。まだ何も行動しなくていい。
