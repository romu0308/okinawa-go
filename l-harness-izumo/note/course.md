# 出雲の縁切り実践講座｜合わない縁を、揉めずに整理して、新しい縁を選ぶ

「切りたい縁があるのに、動けない」
「切ったあとの罪悪感が消えない」

この講座は、そういう人のために作った。

■ この講座で渡すもの

配信やレポートで伝えてきたのは、この講座の入口部分だ。
本編は、あなたの状況に当てはめて、実際に動けるところまで落とし込んである。

第1章 なぜあなたは縁を握り続けるのか
　恩・共通の知人・「切った自分」への嫌悪。握り続ける理由を分解する

第2章 切っていい縁・整理で済む縁の見分け方
　「いい人か」と「自分に合うか」を切り分ける。会った後の自分で判断する基準

第3章 揉めずに距離を取る手順
　返信速度→頻度→物理的距離→説明。順番と、各段階でやってはいけないこと

第4章 家族・職場など切れない縁との付き合い方
　切れない相手に対して「消耗だけを減らす」境界線の引き方

第5章 離れた後の罪悪感の扱い方
　罪悪感が出るのは正常。長引かせない受け止め方

第6章 新しい縁の選び方
　空いた場所に何を入れるか。いい縁を残す習慣

・切りたい縁があり、一人では踏ん切りがつかない

■ 向いていない人

・「受けたら勝手に縁が切れる」を期待している
